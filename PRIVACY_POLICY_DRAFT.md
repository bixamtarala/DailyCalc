# DailyCalc Privacy Policy — Release Draft

DailyCalc is an offline-first calculator application. Core calculator inputs are processed on the user's device and the app does not require an account for core use.

## Advertising
A future production release may use Google Mobile Ads (AdMob). Before advertising is enabled publicly, this policy and the Google Play Data Safety declaration must be updated to match the actual SDK configuration and data practices.

## Local data
Core calculations do not require a DailyCalc backend or cloud database.
